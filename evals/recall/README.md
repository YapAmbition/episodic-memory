# 固定召回回归集

本目录提供版本化、可重复的检索质量评测，不替代单元测试。默认直接运行共享核心，使用临时数据库；不接触正在运行的服务、已有记忆、模型 Key，不执行整理和聊天生成。

## 首版数据

`corpus.json`：16 件人工固定事件，包含项目对话主题的改写与虚构生活场景。固定实验时间、事件 ID、发生/得知时间、显著程度、锚点和关联。不是聊天全文导出，也不是新的真实整理评测。

| 文件 | 问题数 | 用途 |
|---|---:|---|
| lexical.json | 6 | 明确关键词、名称、细节 |
| semantic.json | 8 | 同义改写、口语表达、较弱关键词重合 |
| graph.json | 4 | 同一次查询需要找回多件关联事件 |
| context.json | 4 | 依靠前文理解连续追问 |
| negative.json | 6 | 3 个无答案问题、未来得知/归档排除、1 个未来计划事件的正例 |

共 28 题，23 个正例、5 个负例。语义组不是“严格零关键词重合”。人物关注、跨空间隔离、大规模干扰数据及整理质量仍由其他测试覆盖或留待扩充，不能用本集证明这些能力。未来计划正例只检验事件是否找到，不检验模型是否正确回答“尚未发生”。

## 每次改动后运行

在项目根目录：

```bash
.venv/bin/python scripts/evaluate_recall.py \
  --compare evals/recall/baselines/local-v1.json \
  --output eval-results/recall.json
```

默认 local，不联网、不需要运行后端。输出 JSON 逐题结果和同名 Markdown 汇总。初次建立其他基线时不传 `--compare`。生成的 `eval-results/` 已忽略；人工审核后才把选定结果放入 baselines，不能为消除失败自动覆盖基线。

退出码：0 完成且无已知退步；1 有逐题退步；2 配置/运行失败。与既有基线相比，丢失命中、首次命中排名下降、负例开始返回事件、新增禁止事件或新增降级都会被标记。基线本来失败的题继续失败不会阻止运行，仍完整列在报告中。运行耗时不做自动门禁，受机器负载影响。

同一数据、k、记忆配置及 embedding 配置才允许比较。修改数据后升版本并重新审核基线。报告包含数据和核心源码 SHA256；比较不要求核心哈希相同，因为目的就是比较代码改动。

## 可选真实 Embedding 评测

当前网页填写的 Key 只在服务内存中，本脚本不会读取或导出它。通过当前终端环境提供测试配置：

```bash
export EMBEDDING_BASE_URL='https://your-provider.example/v1'
export EMBEDDING_MODEL='your-embedding-model'
# EMBEDDING_API_KEY 请用安全方式注入当前进程环境，不写进仓库或命令历史。
.venv/bin/python scripts/evaluate_recall.py --mode both \
  --output eval-results/hybrid.json
```

`--mode both` 对同一语料分别跑 local/hybrid。会将本目录事件及查询发到指定远程服务，产生索引和查询请求；先完整建立临时索引，再计召回耗时，索引耗时不计入查询耗时。`--timeout` 默认 1.5 秒。每次独立重建，适合发版前测试，不建议每次保存文件就跑。模型不可用导致建索引失败时退出 2，不把没建好的结果当混合召回成绩；查询期间降级则在报告中标出。不同模型结果不要直接替换同一个基线。服务方在相同模型名下更新权重仍可能影响可重复性。

## 指标解释

- Hit@5：有答案的题里，前 5 个实际输出事件至少命中一个预期事件的比例。
- Recall@5：每题命中的预期事件数 / 该题全部预期事件数，再对正例取平均。多事件题不只“碰到一个就算全对”。
- MRR@5：第一个正确事件排名的倒数，未命中为 0。
- Negative FPR：无答案的题中，返回任意事件的比例；检查全部输出，不限前 5。
- forbidden_cases：返回未来尚未得知或归档事件等明确禁止项的题数。
- 延迟：共享核心调用的本机墙钟耗时，包含召回记录落盘，不包含 HTTP 客户端或聊天模型生成；不是线上端到端聊天延迟。
- 降级数：hybrid 退回程序检索等情况，避免误把降级成绩称为向量效果。

本集只标注必须找回的事件和明确禁止事件，不声称所有额外关联都错误，因此不计算未充分标注的 Precision。不是通用聊天准确率或最终答案正确率。

## 首次基线

local：Hit@5 / Recall@5 均为 18/23（78.3%）；语义改写 3/8，其余正例组全部命中；负例误召回 0/5，禁止事件 0。重复运行逐题结果一致。这里的样本、事件和时间与此前真实对话的 10 题测试不同，不能直接比较百分比。

## 网页操作

左侧「召回测试」→选择「程序召回」或「程序 + Embedding 对照」→「开始测试」。对照模式复用当前空间已保存的向量连接及内存密钥，无需命令行环境变量；仅发送固定测试数据，不复制用户事件。页面展示分组指标、固定 local 基线差异、逐题预期/实际事件和正文，可筛选失败或退步并导出 JSON。历史最多保留 20 次，保存在服务内存中，重启清空；需长期留存请导出。只允许一个测试任务同时运行，关闭服务会取消任务并清理临时目录。

接口：`POST /api/v1/spaces/{sid}/benchmarks?mode=local|both` 提交；`GET /api/v1/benchmarks` 查看进度和结果。使用与其他 API 相同的认证。
